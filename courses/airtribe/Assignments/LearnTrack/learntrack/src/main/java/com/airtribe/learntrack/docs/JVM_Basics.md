# JVM Understanding

Q1. What is JDK, JRE, JVM ?

Answer: 
1. JDK stands for Java Development Kit, it contains everything that is need to build a java application. It consists of JRE and other development kits like compiler, debugger, javadocs etc.

2. JRE stands for Java runtime Environment, It consists of JVM and standard class libraries required to run a java application. It perform class loading, bytecode verification and execution using jvm.

3. JVM stands for Java Virtual Machine, this is the main execution engine in java. It helps to convert bytecode to machine readable instructions. JVM makes java platform independent i.e. WORA - "write once read anywhere". It performs the following four steps:

    - Class Loading: class loader loads bytecode into memory.
    - Linking: performs bytecode verification, preparation, and resolution.
    - Initialization: executes class constructors and static initializers.
    - Execution: interprets or compiles bytecode into native code.

Q2. What is bytecode ?

Answer: 
Bytecode is generated by java compiler when we run `javac` command. Bytecode is intermediate code generated from `.java` files which is stored in `.class` files and is executed by JVM, bytecode make java platform independence. JVM can convert bytecode to platform dependent machine-specific code.

Q3. What does “write once, run anywhere” mean (1–2 short paragraphs)?

Answer: 
WORA - "write once, run anywhere" means you write your java code one time and it can run without making single change on any system which is capable of running jvm.
