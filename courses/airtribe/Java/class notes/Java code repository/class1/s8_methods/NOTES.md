# Methods and Constructors

## What is a Method?
A reusable block of code that performs a specific task.

```java
returnType methodName(parameters) {
    // body
    return value; // if returnType is not void
}
```

## Key Parts
| Part         | Description                              |
|--------------|------------------------------------------|
| Return Type  | Type of value returned (`int`, `void`)   |
| Method Name  | Name to call the method                  |
| Parameters   | Inputs the method accepts                |
| Body         | The code that runs                       |

## Static vs Instance Methods
| Feature      | Static Method              | Instance Method          |
|--------------|----------------------------|--------------------------|
| Keyword      | `static`                   | (no static)              |
| Call via     | ClassName.method()         | object.method()          |
| Access       | Only static fields         | All fields               |
| Use for      | Utilities / helpers        | Object behaviour         |

## Constructors
A special method called automatically when an object is created.
- **No return type** (not even void)
- Same name as the class

### Types
| Type          | Description                              |
|---------------|------------------------------------------|
| Default       | Auto-generated by Java if none written   |
| No-arg        | Written by you, no parameters            |
| Parameterized | Accepts values to set fields             |
| Copy          | Creates a new object from an existing one|
